## 3. What these numbers do not mean

These counts do **not** mean:

- 69 documents = the owner's “3,000 documentation” target;
- 67 documentation Markdown files = 67 guide units;
- 24 PNGs = 24 finished production assets;
- 50 test-source files = 50 passing tests;
- 90 files under `docs/` = 90 canonical authorities.

The program must not collapse unlike metrics into a single completion percentage.

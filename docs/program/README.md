## Purpose

This directory decomposes the owner's documentation-first mandate into coordinated areas that can be expanded independently without losing cross-project consistency.

This is not a claim that the full game is already documented. It is the control layer for producing that documentation in a traceable order.

## Authority order

1. Current repository files and exact branch/HEAD.
2. Fresh executed build/test/runtime evidence.
3. Explicit owner decisions recorded in this program.
4. Existing canonical/game-foundation documents.
5. Area-specific plans and proposals.
6. External references.
7. Chat memory and historical summaries.

When a newer explicit decision supersedes an older note, preserve both and mark the older one superseded rather than deleting history.

## Program rule

Documentation is produced to reduce implementation ambiguity. Document count is not a quality metric by itself. The large volume targets are treated as capacity goals and decomposition targets, not permission to create filler.

## External-reference handling

The six supplied visual references are non-authoritative external material.

Adoptable ideas include:
- modular settlement planning;
- functional zones and readable circulation;
- reusable architecture/prop families;
- layered character/equipment presentation;
- UI panels tied to character/scene context;
- icon/FX families;
- reusable overlays;
- production-stage tracking.

Do not import:
- proprietary names;
- exact world lore;
- exact character identities;
- contradictory numbers;
- copied layouts as one-to-one maps;
- unique protected expression.

## Current pilot

Gate Twelve District remains the first detailed spatial/application pilot. It validates the documentation process before the same contracts expand to the larger world.

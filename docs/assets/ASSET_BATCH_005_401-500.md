## Visibility rule

Feedback assets run only from resolved/player-safe state. They may not predict checks, reveal hidden conditions, expose undiscovered routes, or turn raw internal flags into player-visible spoilers.

## DONE gate

All 100 units require manifest/blueprint lineage. Developer/reference-only assets must be excluded from normal production presentation unless explicitly designed as a safe runtime fallback.

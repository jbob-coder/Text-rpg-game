# THE GAME — Asset Production Batch 001 (001–100)

Batch status: **PLANNED / DOCUMENTED**. No item in this catalog is automatically generated, integrated or canon-approved by appearing here.

This is the first exact 100-unit production batch. It is grounded in the current playable content and the reusable systems required to stop one-off art from accumulating.

## How to read an asset unit

One catalog unit may produce more than one physical file when the unit is inherently a sheet or set (for example, a six-view turnaround or animation sheet). The unit still has one stable production ID and one acceptance record.

Every unit inherits:

- the pixel-grid and palette rules in `PIXEL_ASSET_MASTER_PLAN.md`;
- character anchors from `CHARACTER_PIXEL_BLUEPRINTS.md`;
- reference-to-blueprint lineage requirements;
- authoritative-state ownership: art renders state but never decides it.

## Priority waves

### Wave A — Visual foundation (001–020)
Player/Tamsin identity, rig, animation and portrait rules. These assets must be stable before mass equipment generation.

### Wave B — Current authored objects/equipment (021–040)
Every current opening-loadout item plus relay states and Tamsin identity gear. This ties authoritative inventory/equipment to visible art.

### Wave C — Current world (041–065)
All nine current map/location identities, state variants and shared environmental modules.

### Wave D — Interactable props (066–075)
Reusable props required by current scenes and lore/world interactions.

### Wave E — UI/map semantics (076–095)
Pixel icons for navigation, resources, quests and authoritative map states.

### Wave F — Trace/transition FX (096–100)
Visual effects for current ability progression and map travel.

- a locked brief;
- selected reference or explicit no-reference decision;
- reconstructable pixel blueprint;
- native master;
- manifest record;
- integration path or documented deferred integration;
- visual QA at native scale;
- Android-scale QA if player-facing;
- authoritative-state mapping where dynamic;
- source/reference lineage.

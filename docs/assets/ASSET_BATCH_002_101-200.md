# THE GAME — Asset Production Batch 002 (101–200)

Status: **PLANNED / DOCUMENTED**.

Purpose: complete the reusable character/NPC production system after Batch 001 establishes the current player/Tamsin vertical slice.

All generic NPC entries are **technical/non-canon framework assets** until authored content assigns a stable named identity. They must never silently become story canon.

## Batch goals

- broaden player customization without breaking paper-doll anchors;
- define directional/interact animation coverage;
- standardize portrait/emotion construction;
- provide reusable NPC body archetypes;
- separate role clothing from identity;
- provide social/status overlays that respect player-safe visibility;
- provide staging/accessibility/debug assets.

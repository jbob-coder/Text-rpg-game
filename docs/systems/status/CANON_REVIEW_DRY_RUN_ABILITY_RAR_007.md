## 3. Governing law

Memory Echo reads fragmentary residual impressions associated with emotionally intense past contact on valid objects or locations.

Hard boundaries:
- not living mind reading;
- not objective historical playback;
- no guaranteed identity;
- no guaranteed chronology;
- no automatic causation;
- residue can decay;
- residue can overlap;
- decoys/contamination can mislead;
- user interpretation remains fallible;
- memories cannot be altered by this ability.

## 4. Rarity fit

Rare remains plausible because Memory Echo:
- accesses information outside ordinary senses;
- can materially influence investigation, history, research, intelligence, privacy, and evidence systems;
- still has strong natural uncertainty/counterplay.

The ability's significance comes from information access, not combat output.

## 5. Technique ladder

Current progression:
1. `Surface Echo` — strongest accessible residue;
2. `Echo Isolate` — attempts to separate one residue from overlap;
3. `Context Thread` — holds related fragments for probable sequencing;
4. `Deep Resonance` — greater sensory/emotional depth from one strong Echo.

The ladder increases discrimination, context handling, and depth without changing the core law.

## 6. Evidence and truth separation

Resolved:
- raw Echo impression is an observation/evidence source;
- interpretation is stored separately;
- confidence is not objective truth;
- repeated reading of the same Echo is not independent corroboration;
- conflicting evidence must remain preserved;
- hidden world truth is never projected solely because the engine knows it.

This is a major promotion-strength requirement and is now documented.

## 7. Contamination/counterplay

Established counter/failure routes:
- weak residue;
- time decay;
- overlapping events;
- deliberate decoys;
- similar emotional signatures;
- damaged/altered source;
- user bias;
- missing context;
- emotional bleed;
- exhaustion.

Counterplay is therefore broader than simply “resist the power.”

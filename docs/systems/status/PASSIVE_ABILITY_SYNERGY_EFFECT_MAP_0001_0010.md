# THE GAME — Ability Synergy Passive Effect Map 0001–0010

Status: **PHASE-C CALIBRATION / NOT CANON / NOT IMPLEMENTED**

Purpose: deepen the existing `PASSIVE_SYN_0001`–`PASSIVE_SYN_0010` records without changing IDs or compact-wave identity.

| ID | Existing name | Bounded design effect |
|---|---|---|
| PASSIVE_SYN_0001 | Resource Cycling | Improves transition between primary-ability exertion and ordinary recovery behavior without creating extra energy or resources. |
| PASSIVE_SYN_0002 | Technique Compression | Reduces unnecessary execution steps in a thoroughly mastered known technique. |
| PASSIVE_SYN_0003 | Cast Stability | Reduces avoidable instability during repeated use of a known primary-ability technique. |
| PASSIVE_SYN_0004 | Overuse Warning | Improves recognition of the user's own established warning signs before dangerous ability overuse. |
| PASSIVE_SYN_0005 | Recovery Channel | Improves post-ability recovery behavior within existing recovery rules. |
| PASSIVE_SYN_0006 | Precision Scaling | Improves control when deliberately operating a known ability below maximum output for precision. |
| PASSIVE_SYN_0007 | Dual-Task Control | Reduces performance loss while maintaining a simple known ability effect and performing a familiar secondary task. |
| PASSIVE_SYN_0008 | Counter-Feedback | Improves learning from documented cases where the user's ability was successfully countered. |
| PASSIVE_SYN_0009 | Ability Familiarity | Reduces Focus overhead for extremely familiar low-complexity ability use. |
| PASSIVE_SYN_0010 | Evolution Sensitivity | Improves recognition of legitimate signs that a known technique may be approaching a discovery/evolution threshold. |

## Family guardrails

- These passives never create a second primary ability.
- They do not bypass the parent ability's core law, rarity, costs, or forbidden domains.
- Technique Compression cannot remove mandatory physical/system requirements.
- Overuse Warning does not prevent overuse automatically.
- Evolution Sensitivity does not reveal hidden future techniques by name or guarantee that evolution exists.
- Same-resolver effects require capped composition.
- Duplicate ownership never stacks.
- Exact numeric values remain `TBD`.

## Promotion blockers

Ability-use state ownership, mastery/technique prerequisites, warning/strain taxonomy, recovery integration, evolution/discovery visibility, cross-family stacking, knowledge review, numeric calibration, save/projection behavior, and tests remain open.

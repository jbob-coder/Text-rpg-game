## Readiness vocabulary

- `PARENT_MODEL_MISSING` — base parent system is not mature enough for numeric ranges.
- `FIXTURE_SCHEMA_READY` — required test shape is known.

- `RANGE_FIXTURES_READY` — parent system has justified candidate ranges/expected outputs.
- `EXECUTABLE_FIXTURES_READY` — deterministic runtime/formal simulation executes the fixtures.

## Mapping rules

1. A role class indicates relevance, not ownership or guaranteed knowledge.
2. Named organizations must come from parent world documentation.
3. A family can have different role-class importance by region and historical period.
4. Public knowledge of an effect does not reveal hidden Status qualification.
5. Classification must identify the exact restricted datum: existence, method, trigger, identity, history, or doctrine.
6. Profession/training value does not automatically imply legal permission.

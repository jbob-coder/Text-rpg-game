## Audit rule

Legendary must change civilization-scale possibility while still preserving hard prerequisites, finite scope, and reconstructable failure rules.

## ABILITY_LEG_001 — Event Reversal

Result: **PASS WITH FOUNDATIONAL MODEL BLOCKER**

Nearest lower-tier relationships:
- Causal Mark restores one recorded bounded property.
- Time Partition changes subjective processing, not physical history.
- Temporal Drag changes process rate, not resolved state.

Legendary distinction:
Event Reversal operates on a recent bounded zone-state snapshot rather than one property or one process rate.

Hard blockers:
- snapshot authority;
- living-body/memory semantics;
- conservation/accounting;
- objects crossing the zone boundary;
- explicit anchor conflict rules;
- repeated-use system strain;
- save/reload anti-exploit behavior.

Failure threshold:
If it can restore undefined state, resurrect by default, or rewind without a valid recent reference, it no longer has a reconstructable Legendary law.

## ABILITY_LEG_002 — World Gate

Result: **PASS WITH WORLD-INFRASTRUCTURE BLOCKER**

Nearest lower-tier relationships:
- Fold Step folds a short stable path.
- Spatial Dominion changes path geometry inside a bounded field.

Legendary distinction:
World Gate connects prepared calibrated anchors over civilization-scale distance and therefore changes transport/logistics architecture.

Hard blockers:
- anchor creation/calibration;
- coordinate/reference frames;
- transit semantics;
- aperture/throughput;
- energy supply;
- pressure/environment transfer;
- authentication/security;
- world ownership and law.

Failure threshold:
If it works without anchors, preparation, or meaningful energy; or becomes arbitrary dimension travel; it collapses the tier boundary.

- techniques `TECH_SEP_001_T1`–`T4`

Purpose: resolve the non-numeric model for subjective processing acceleration, sensory-information limits, decision queues, physical action latency, cognitive/metabolic strain, exit reconciliation, and interaction with other time effects.

## 1. Core law

Time Partition accelerates the user's **subjective perception-processing, planning, and neural decision work** relative to ordinary surrounding world events.

It does not:
- stop world time;
- rewind time;
- accelerate the user's full body automatically;
- grant additional physical movement distance;
- create extra external events;
- reveal future events;
- make missing information available;
- guarantee better decisions.

The world retains one authoritative monotonic `world_time`.

## 2. Two-rate model

The ability requires separation between:

`EXTERNAL_WORLD_RATE`
- authoritative world/event progression;
- ordinary physics;
- other entities' actions;
- projectile motion;
- environmental change.

`SUBJECTIVE_PROCESSING_RATE`
- user's internal perception/interpretation/planning work.

Time Partition changes the second.

It does not replace the first.

## 3. Subjective work budget

A future activation should track a bounded internal processing budget rather than spawning extra world-time turns.

Potential authoritative fields:
- activation ID;
- owner;
- start world time;
- current partition state;
- subjective acceleration band/factor;
- subjective processing budget consumed;
- Focus/Resolve/Stamina cost;
- cognitive/metabolic strain;
- exit/recovery state;
- last committed update.

Exact factor and budget units remain `TBD`.

## 4. Sensory input boundary

Accelerated processing does not create sensory information that never reached the user.

The sensory pipeline must distinguish:
- external signal availability;
- physical/sensory capture;
- neural processing/interpretation.

Time Partition may:
- reduce internal interpretation latency;
- allow more internal analysis of available ongoing input;
- support faster comparison between already available observations.

It may not:
- see through occlusion;
- hear absent sound;
- read hidden state;
- reconstruct arbitrary data between unavailable samples;
- turn ambiguous input into objective truth.

Exact sensory-transduction acceleration, if any, remains a future physiology/design decision.

## 5. No physical-speed inheritance

The user's muscles, joints, inertia, equipment, and movement remain governed by ordinary physical/action systems unless another effect changes them.

Therefore:
- thinking of four actions does not execute four actions;
- attack cadence is not multiplied automatically;
- running speed is not multiplied automatically;
- recoil and balance remain ordinary;
- reaction choice can improve while reaction execution remains mechanically bounded.

## 6. Decision queue

Time Partition can produce planned candidate actions faster than the body can execute them.

A future decision record may contain:
- candidate action ID;
- planning snapshot/context;
- priority;
- assumptions;
- validation state;
- expiry/staleness marker.

Before physical commit, the chosen action must be revalidated against current world state.

A plan can become stale while the user is still physically unable to act.

## 7. Action-latency rule

The ability may reduce **decision latency**.

It does not automatically reduce:
- animation/action duration;
- weapon cycling time;
- movement travel time;
- mechanical reload time;
- bodily acceleration;
- tool process time.

If another system contains a cognitive component inside action startup, only that eligible cognitive portion may benefit.

Mandatory physical time remains mandatory.

## 8. Thought Stretch — T1

`TECH_SEP_001_T1 Thought Stretch` opens one brief subjective decision window.

Authorized use:
- examine available current observations;
- compare immediate responses;
- choose one action more deliberately.

Not authorized:
- multiple physical actions inside one ordinary action window;
- prediction of information not yet observed.

## 9. Decision Lattice — T2

`TECH_SEP_001_T2 Decision Lattice` evaluates several candidate action plans before commitment.

Rules:
- every branch uses only information currently available to the character;
- branches are hypothetical models, not future timelines;
- branch quality depends on character knowledge/skills;
- deceptive or missing information can contaminate every branch;
- one selected action still commits through ordinary action rules.

The lattice is planning, not precognition.

## 10. Partition Hold — T3

`TECH_SEP_001_T3 Partition Hold` sustains increased subjective processing across a bounded sequence of world events.

Requirements:
- continuous resource/strain handling;
- current sensory/context revalidation;
- bounded duration;
- accumulation of cognitive/metabolic burden.

As external events evolve, old plans must be updated or discarded.

## 11. High Partition — T4

`TECH_SEP_001_T4 High Partition` uses the strongest approved short-duration subjective acceleration.

Expected structural risks:
- sensory overload;
- decision saturation;
- severe Focus/Resolve demand;
- Stamina/metabolic burden;
- post-effect disorientation;
- degraded subsequent performance/recovery debt.

It does not remove body-speed limits.

## 12. Cognitive saturation

More subjective processing is not infinitely useful.

A future model should support one or more limits such as:
- working-memory capacity;
- number of meaningful candidate plans;
- evidence complexity;
- sensory integration bandwidth;
- decision fatigue;
- strain threshold.

This prevents the ability from becoming unlimited brute-force search.

Exact model remains `TBD`.

## 13. Bad information rule

Time Partition improves processing opportunity, not input truth.

If inputs are:
- false;
- incomplete;
- deceptive;
- outdated;
- misunderstood,

the user can still make a wrong decision faster and with more internal analysis.

The knowledge/evidence/confidence standard remains authoritative.

## 14. Skill interaction

Skills may improve what the user can do with subjective time.

Examples:
- Tactics can improve combat planning;
- Investigation can improve evidence evaluation;
- Technical Systems can improve diagnosis;
- Leadership can improve command planning.

Time Partition does not grant these skills.

A low-skill user receives more thinking time but not expert knowledge.

## 15. Resource model

Current ability record uses:
- Focus;
- Resolve;
- Stamina.

Structural interpretation:
- Focus supports concentrated processing;
- Resolve supports sustained cognitive control under overload;
- Stamina represents bodily/metabolic burden.

No conversion between these resources is implied.

Exact costs remain `TBD`.

## 16. Strain and recovery

Time Partition needs a dedicated strain/recovery model or a clearly owned parent state.

Possible structural terms:
- acute cognitive strain;
- sensory overload;
- metabolic fatigue;
- exit disorientation;
- recovery lockout/debt.

The ability must not be infinitely chain-cast merely because core resources remain above zero.

Exact thresholds/durations remain open.

## 17. Exit reconciliation

When partition ends:
- world time has advanced normally;
- current sensory/world state becomes the sole action authority;
- stale internal plans remain only as memory/planning artifacts;
- ordinary perception/action timing resumes.

Possible failure states:
- disorientation;
- delayed commitment;
- mistaken reliance on stale plan;
- short recovery impairment.

Exit does not rewind to the activation moment.

## 18. Temporal Drag interaction

`Temporal Drag` changes process rate in an external bounded zone.

Time Partition changes subjective internal processing.

If both effects coexist:
- one authoritative world time remains;
- external process-rate modification resolves through Temporal Drag;
- subjective processing modification resolves through Time Partition;
- effective perceived relationship may change, but neither effect duplicates the other's authority.

No multiplicative “free time stop” is assumed.

## 19. Bioelectric Overdrive interaction

`Bioelectric Overdrive` changes temporary neuromuscular performance.

Time Partition changes subjective processing.

If both coexist:
- decision speed and body-response capability may both improve through separate systems;
- each pays its own resources/strain;
- neither silently inherits the other's multiplier;
- body structural limits remain authoritative.

A combined build therefore requires explicit ordered-stage composition, not one merged speed stat.

## 20. Probability Tilt boundary

Time Partition can compare options.

Probability Tilt can bias plausible outcome weighting.

Time Partition does not:
- expose hidden probabilities;
- guarantee the best branch;
- infer that Probability Tilt caused one observed outcome.

No automatic cross-ability certainty exists.

## 21. Save/load

If saving during active partition is legal, persist:
- activation ID;
- start/current world time;
- partition state;
- resources already committed;
- strain;
- remaining authorized duration/budget;
- any committed action transaction;
- recovery/lockout.

Loading must not:
- reset costs;
- duplicate subjective budget;
- grant another action;
- revert external world time;
- restore stale candidate plans as guaranteed-valid actions.

## 22. Player-safe projection

Potential visible data:
- Time Partition active/inactive;
- known technique;
- broad strain/recovery warning;
- known remaining control band if the ability legitimately provides it.

Do not display:
- hidden enemy action plans;
- exact unseen event timing;
- future trajectory beyond legitimate prediction systems;
- hidden probability;
- internal engine tick data unless the world mechanic explicitly exposes it.

## 23. World consequences

Plausible role classes:

- command;
- piloting/operations;
- research;
- emergency decision work.

Not established:
- named institution;

World integration remains separate.

## 24. Required future tests

- world time remains monotonic during activation;
- body movement speed does not increase solely from Time Partition;
- one planned branch does not execute without ordinary action validation;
- unavailable sensory data stays unavailable;
- false evidence can still yield wrong plans;
- T1 grants one bounded decision window;
- T2 branches are hypothetical, not future-state copies;
- T3 revalidates changing world state;
- T4 accumulates severe bounded strain;
- activation cannot create extra physical action count;
- Temporal Drag composition keeps one world clock;
- Bioelectric Overdrive composition remains separate;
- save/load cannot duplicate budget/action or reset strain;
- player-safe UI leaks no future/hidden information.

## ABILITY_LEG_001 — Event Reversal

Core law:
Returns a bounded zone to a recently recorded physical state while preserving explicitly excluded anchors.

Hard boundaries:
- a valid recent reference state must exist;
- radius and time window are finite;
- exclusions must be explicitly defined rather than inferred after activation;
- only state included by the final reversal model is restored;
- no unlimited rewind of world history;
- no resurrection assumption;
- no automatic memory/identity rewrite;
- repeated use rapidly increases system strain;
- exact handling of living bodies, memory, projectiles in transit, consumed resources, and objects crossing the zone boundary remains `TBD`.

Lower-tier boundary:
- `ABILITY_EPI_001 Causal Mark` records one bounded physical property on one target and restores that property;
- Event Reversal restores a broader recent **zone state**, making the governing unit an event-space snapshot rather than one property.
- `ABILITY_SEP_001 Time Partition` only changes subjective processing and does not rewind anything.

Why Legendary:
The ability can reverse a bounded physical event state rather than modifying one object/property or one local process rate. Even with strict limits, this can invalidate ordinary consequences inside the zone.

Resources:
Focus + Resolve + system strain.

Progression:
small recent snapshot → stable bounded restore → selective anchor exclusions → larger divergence restore → advanced tightly controlled event-state reversal.

Counters:
prevent/deny a valid reference state, exceed the time window, leave the zone, force many ambiguous boundary crossings, exploit excluded anchors, create repeated strain, apply higher-order law/system counters where later defined.

Failure modes:
partial restore, anchor conflict, boundary mismatch, restored geometry colliding with excluded state, severe system strain, uncertainty around living-state reconciliation until canon rules exist.

World roles:
disaster response, strategic containment, infrastructure recovery, research, high-level security, historical/legal controversy.

Critical blockers before promotion:
- authoritative snapshot semantics;
- living-body and memory treatment;
- conservation/accounting rules;
- zone-boundary crossing;
- anchor conflict resolution;
- repeated-use strain;
- save/reload anti-exploit rules;
- legal/evidence consequences.

Upper-tier guardrail:
Must not become unrestricted timeline editing, resurrection, omniscient history access, or Prime Legendary law suppression.

## ABILITY_LEG_002 — World Gate

Core law:
Creates a stable long-distance gateway between previously calibrated spatial anchors, potentially across planetary or interplanetary distances.

Hard boundaries:
- endpoints require valid calibrated anchors;
- opening requires preparation and major external energy;
- endpoint identity/calibration cannot be guessed;
- no instant unanchored combat teleport;
- gate aperture, duration, throughput, mass limit, pressure/environment transfer, and transit rules remain `TBD`;
- anchor destruction or calibration drift can prevent opening;
- gate does not automatically make hostile environments safe;
- no arbitrary dimensional travel unless separately authored.

Lower-tier boundary:
- `ABILITY_SRR_002 Fold Step` temporarily shortens a visible local path between stable endpoints;
- `ABILITY_EPI_004 Spatial Dominion` alters path geometry inside a bounded field;
- World Gate creates a persistent prepared long-distance connection between calibrated anchors far beyond local line-of-sight geometry.

Why Legendary:
It changes civilization-scale transport and logistics. Even strict gate limits can alter trade, migration, military planning, research, and planetary access.

Resources:
Focus + massive external energy; calibration infrastructure and preparation are required.

Progression:
single known anchor pair → stable aperture → controlled throughput → longer-distance calibrated pair → advanced high-load stable gate operation.

Counters:
deny/damage anchors, disrupt calibration, deny external energy, exploit opening time, introduce reference drift, overload permitted throughput, apply spatial/law counters where later defined.

Failure modes:
failed lock, aperture collapse, transit interruption, environmental transfer hazards, anchor mismatch, severe energy loss, spatial instability.

World roles:
transport networks, exploration, logistics, trade, strategic infrastructure, emergency evacuation, planetary/interplanetary civilization.

Critical blockers before promotion:
- anchor creation/calibration rules;
- coordinate/reference-frame model;
- transit semantics;
- aperture/throughput limits;
- energy source model;
- pressure/atmosphere transfer;
- gate security/identity/authentication;
- infrastructure ownership and law.

Upper-tier guardrail:
Must not become free unanchored teleportation, arbitrary dimension access, or global spatial rewriting.

Legendary abilities can alter the practical rules of civilization, but remain reconstructable through strict prerequisites, bounded scope, and explicit failure states.

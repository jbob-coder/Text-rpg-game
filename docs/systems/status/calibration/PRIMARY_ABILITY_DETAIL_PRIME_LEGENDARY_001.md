## ABILITY_PRL_001 — Law Silence

### Identity
- rarity: **Prime Legendary**
- family: `law`
- stable version: `0.1-calibration`
- design status: `CALIBRATION_PROPOSAL`
- canon status: `NOT_CANON_UNTIL_PROMOTED`
- implementation status: `NOT_IMPLEMENTED`

### Core law
Temporarily suppresses one precisely understood interaction rule inside a small bounded field.

The ability acts on the interaction rule itself rather than merely overpowering one instance of that rule.

### What counts as an interaction rule
A valid target must eventually be represented as an explicitly modeled interaction with:
- defined participants or domains;
- defined trigger conditions;
- defined result;
- defined spatial/temporal scope;
- a sufficiently understood mechanism.

Examples must come from approved game systems after those systems are documented. This file does not create a universal list of suppressible laws.

### Hard boundaries
- only one precisely understood rule at a time by default;
- field is small and temporary;
- suppression is bounded by scope, duration, and system strain;
- the user cannot suppress an undefined concept;
- the user cannot simply declare an outcome such as “damage does not exist”;
- the ability does not suppress the Status system by default;
- it does not rewrite history;
- it does not permanently change physical or system law;
- it does not automatically identify hidden rules;
- it does not grant omniscience about what rules exist;
- it does not automatically bypass higher-order safeguards;
- exact targetable-law taxonomy remains `TBD`.

### Legendary boundary
Compared with `ABILITY_LEG_001 Event Reversal`:
- Event Reversal restores a bounded recent physical state;
- Law Silence temporarily suppresses one interaction rule governing present resolution.

Compared with `ABILITY_LEG_002 World Gate`:
- World Gate uses spatial law through prepared infrastructure;
- Law Silence can potentially suppress one modeled interaction rule but does not provide transport or create a gate.

Prime Legendary superiority comes from **rule-level intervention**, not simply larger scale or higher output.

### Rarity rationale
Prime Legendary because the user can alter whether one understood interaction resolves at all inside a bounded field. Ordinary Legendary doctrine may not be sufficient because each legal target rule can create a different strategic effect.

This tier remains justified only if:
- valid laws are tightly typed;
- the field is small;
- knowledge prerequisites are severe;
- resource/backlash costs are severe;
- counterplay exists through scope, knowledge, timing, rule selection, and recovery.

### Classification confidence
Provisional Prime Legendary classification: **HIGH if the typed-law model remains strict**.

If the ability becomes open-ended concept negation, the record fails reconstruction and balance review.

### Attributes / skills
Likely dependencies:
- Intellect — formal understanding of the target interaction;
- Perception — identifying conditions and field boundaries;
- Will — holding the suppression coherently;
- Resolve — resisting backlash/system strain.

Relevant skills:
- Powers;
- Technical Systems where applicable;
- Investigation;
- specialized scientific/technical knowledge;
- Tactics for timing and field use.

Exact dependencies remain `TBD`.

### Resource model
Primary:
- Focus;
- Resolve;
- system strain.

Cost should increase with:
- rule complexity;
- field size;
- duration;
- number of active interaction participants;
- mismatch between user understanding and actual rule behavior;
- attempts to suppress unusually fundamental/high-order interactions.

No “free” suppression exists.

### Mastery path
1. identify one approved simple interaction;
2. create a minimal suppression field;
3. define field boundary reliably;
4. sustain the same known suppression briefly;
5. select among several separately learned/validated rules;
6. advanced application: suppress one highly complex known rule under severe cost.

Mastery expands **precision and validated rule library**, not unrestricted authority.

### Technique/evolution boundary
Techniques may:
- improve rule identification;
- narrow field shape;
- improve timing;
- reduce waste;
- sustain one learned suppression;
- manage backlash.

Techniques may not:
- suppress several unrelated rules at once without a separately reviewed evolution;
- permanently delete laws;
- edit Status architecture;
- create arbitrary desired outcomes.

No evolution is approved in this packet.

### Counters / weaknesses
Primary counter routes:
- force the user into a rule they do not understand well enough;
- change interaction conditions so the selected rule no longer matches;
- leave the field;
- break concentration;
- force repeated activations and accumulate system strain;
- exploit unsuppressed parallel mechanisms;
- use higher-order or specially protected interactions if later authored.

### Failure modes
- no effect because the selected rule definition is invalid;
- partial/unstable suppression;
- wrong interaction targeted;
- field collapse;
- severe system strain;
- rebound or delayed resolution if the future law model defines one;
- dangerous mismatch between suppressed and unsuppressed linked systems.

Exact rebound behavior remains `TBD`; do not improvise it in implementation.

### World consequence
A confirmed Law Silence user would likely be a civilization-level strategic concern because the ability can invalidate specific known interaction doctrine.

Potential interest:
- top-level government/security;
- research institutions;
- strategic infrastructure authorities;
- organizations studying abilities/system law;
- groups seeking containment, recruitment, secrecy, or access.

Named institutions are intentionally deferred until world integration.

### Public / classified knowledge
Provisional posture:
- public may know the rarity/name only if disclosure rules permit;
- exact suppressible-law library should not be assumed public;
- high-tier institutions may possess partial doctrine;
- full understanding may remain incomplete even among elite researchers.

### Level-100 compatibility
Level 100 does not automatically expand Law Silence into unlimited rule editing.

If a Level-100 replacement event interacts with this ability, the `LEVEL_100_EXCEPTION_STANDARD.md` governs the exception. This record does not invent replacement mechanics.

### Visual/content requirements
The field must communicate:
- bounded area;
- one selected interaction being suppressed;
- strong distinction between “rule not resolving” and ordinary shield/resistance;
- visible strain/backlash state where player-safe.

Presentation must not visually imply omnipotence or global reality deletion.

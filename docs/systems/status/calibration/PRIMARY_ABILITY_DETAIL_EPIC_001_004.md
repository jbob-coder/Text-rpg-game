## ABILITY_EPI_001 — Causal Mark

Core law:
Records one bounded physical property of a marked target and, within a short valid window, restores that specific property to its recorded value.

Examples of candidate property classes:
- position;
- velocity;
- temperature;
- structural deformation;
- surface damage state;
- charge state;
- other explicitly approved bounded physical properties.

The final whitelist is `TBD`.

Boundaries:
- records only one approved physical property per mark unless later calibrated otherwise;
- does not rewind complete history;
- does not restore unrecorded properties;
- no resurrection;
- no memory restoration;
- no identity restoration;
- no causal edits outside the mark window;
- mark duration, property whitelist, target size/mass, and restoration energy cost remain `TBD`;
- paradox prevention rules are required before implementation.

Why Epic:
Super Rare abilities alter strong but local mechanics. Causal Mark can restore a selected prior physical state without replaying the path that produced it, which changes causal resolution itself.

Resource model:
Focus + Resolve. Cost should scale with property complexity, target scale, elapsed time, and divergence from the recorded state.

Progression:
record simple property → restore simple property → higher precision → stronger divergence recovery → advanced property class.

Counters:
deny marking, outlast the mark window, alter an unrecorded property, exceed target limits, overwhelm resource cost, causal/law counter-effects.

Failure/danger:
restoring one property while related properties remain changed can create dangerous mismatches. Example: restoring position without matching velocity would require an explicit rule rather than an assumed safe outcome.

World roles:
extreme-value research, disaster recovery, containment, security, transport, strategic infrastructure.

Critical blockers:
- approved property whitelist;
- interaction between linked properties;
- conservation/cost model;
- mark ownership and overwrite rules;
- paradox/duplication prevention;
- living-target restrictions.

Upper-tier guardrail:
Must not become free history rewind, resurrection, universal rollback, or save-state restoration.

## ABILITY_EPI_002 — Singularity Seed

Core law:
Creates a tiny temporary high-gravity point with a tightly bounded lifetime and influence radius.

Boundaries:
- not a true astrophysical black hole unless future canon explicitly defines otherwise;
- no infinite density;
- no permanent remnant;
- no planetary-scale field;
- finite radius, force, and lifetime;
- user is not immune to environmental consequences;
- exact field curve, maximum acceleration, energy cost, and structural interaction are `TBD`.

Lower-tier boundaries:
- Gravity Well creates a bounded attraction field.
- Mass Inversion reverses the gravitational response of tagged matter.
- Singularity Seed is Epic because it creates an extreme compact gravity source whose field gradient and local consequences exceed ordinary Rare/Super Rare gravity manipulation.

Resource model:
Focus + Resolve with severe recovery burden.

Progression:
micro-seed → precise placement → controlled lifetime → stronger gradient → advanced compact field management.

Counters:
distance, pre-emptive interruption, Spatial Anchor-style constraints where applicable, prepared high-strength structures, gravity/law counter-effects, resource denial.

Failure/danger:
structural failure, debris acceleration, crushing forces, orbital-like local motion, equipment destruction, user/allied exposure.

World roles:
high-security research, extreme engineering, containment, strategic military doctrine.

Critical blockers:
- whether “singularity” is literal or nomenclature;
- maximum field gradient;
- minimum safe range;
- interaction with structures, fluids, and living bodies;
- cancellation behavior.

Upper-tier guardrail:
No infinite gravity, event horizon, matter deletion, or persistent astronomical singularity by default.

## ABILITY_EPI_003 — Adaptive Arsenal

Core law:
Transforms the user's own tissues into learned biological tools, armor, or weapon structures while preserving overall body viability.

Boundaries:
- self-only by default;
- only learned/encoded templates;
- transformation consumes biomass, energy, hydration, nutrients, and recovery time;
- transformed structures remain biological unless explicitly authored otherwise;
- cannot create arbitrary foreign matter;
- no unlimited mass gain;
- no instant knowledge of every possible form;
- viability of circulation, respiration, neural control, and organ function remains mandatory;
- template learning rules are `TBD`.

Lower-tier boundaries:
- Stonehide mineralizes limited outer tissue.
- Adaptive Regeneration repairs the user.
- Adaptive Arsenal changes body structure deliberately into functional biological forms rather than merely hardening or healing.

Why Epic:
It rewrites the user's body plan temporarily within learned constraints, creating a flexible biological toolkit rather than a single fixed biological enhancement.

Resource model:
Stamina + biological reserve. Focus may be added for precision only if later approved.

Progression:
simple tool form → localized armor/tool → complex limb conversion → rapid template switching → advanced multi-region transformation.

Counters:
resource depletion, unfamiliar required form, template limits, transformation time, damage to transformed tissue, toxins/biological disruption, forced rapid switching.

Failure/danger:
malformed transformation, circulation compromise, nerve mismatch, loss of mobility, metabolic collapse, incomplete reversion.

World roles:
medicine, industry, exploration, military, research, hazardous-environment adaptation.

Critical blockers:
- template acquisition rules;
- mass conservation;
- transformation time;
- biological reserve definition;
- reversion/failure behavior;
- whether transformed tissue can be detached and survive.

Upper-tier guardrail:
No unrestricted shapeshifting, species copying, infinite biomass, or arbitrary matter creation.

## ABILITY_EPI_004 — Spatial Dominion

Core law:
Alters effective distance and path geometry inside a bounded controlled field.

Possible legal effects within the same core law:
- lengthen a path;
- shorten a path;
- redirect a path;
- make two locations inside the field effectively farther/closer;
- alter traversal geometry without changing the external world's topology.

Exact allowed transforms remain `TBD`.

Boundaries:
- field is bounded;
- does not rewrite topology outside the field;
- no permanent world-map edits;
- no unrestricted teleportation;
- no infinite maze;
- no arbitrary dimensional creation;
- sustained use is extremely costly;
- path continuity, line-of-sight behavior, projectiles, sound, fluids, and moving-platform interactions require explicit rules.

Lower-tier boundaries:
- Blink Step relocates self.
- Spatial Anchor resists displacement.
- Fold Step temporarily joins two endpoints.
- Spatial Dominion changes the geometry governing many paths inside an area.

Why Epic:
It changes local spatial rules for every qualifying path in a field rather than creating one movement or one connection.

Resource model:
Focus + Resolve with steep scaling by field size, geometric complexity, number of paths/actors, and duration.

Progression:
single-path distortion → small field → selective path shaping → moving/maintained field → advanced multi-path geometry.

Counters:
leave the field, disrupt concentration, force many simultaneous path calculations, spatial counter-effects, anchor/reference constraints, resource exhaustion.

Failure/danger:
navigation failure, collision, trapped routes, projectile unpredictability, structural access problems, field-collapse disorientation.

World roles:
containment, defense, transport, rescue, architecture research, strategic security.

Critical blockers:
- exact geometric transform model;
- reference frames;
- whether perception sees transformed distance;
- projectile/sound/light path behavior;
- interaction with Fold Step and Spatial Anchor;
- field collapse rules.

Upper-tier guardrail:
Must not become global topology rewrite or permanent spatial-law editing.

# Epic cross-tier audit

Epic rarity is justified only if the ability changes the governing resolution layer:
- Causal Mark: restores one previously recorded property without replaying the intervening history.
- Singularity Seed: creates an extreme compact gravity source rather than ordinary field manipulation.
- Adaptive Arsenal: changes the user's biological form using learned templates.
- Spatial Dominion: changes path geometry for an area rather than moving/anchoring one target.

Potential demotion condition:
If later calibration reduces an Epic ability to merely “stronger Super Rare output,” it should be demoted or redesigned.

Potential promotion condition:
If any record gains unrestricted history rewrite, permanent topology rewrite, resurrection, infinite gravity, or arbitrary biological transformation, it likely exceeds Epic and must be re-audited.

No canon promotion is implied.

# THE GAME — Epic Counterplay Detail 001–004

Status: **CALIBRATION DETAIL / NOT CANON / NOT IMPLEMENTED**

## COUNTER_EPI_001 — Causal Mark

Primary weaknesses:
- marking must occur first;
- only one approved recorded property is restored;
- the restoration window is finite;
- unrelated state remains changed;
- target/property limits remain.

Counterplay:
deny marking, outlast the window, force changes across multiple properties, pressure focus/resolve, use causal/law counter-effects if later authored.

Failure criterion:
The design fails if Causal Mark becomes unrestricted rollback, complete history reversal, or restoration of unrecorded state.

## COUNTER_EPI_002 — Singularity Seed

Primary weaknesses:
- finite radius and lifetime;
- severe control/resource burden;
- placement matters;
- user/environment remain subject to the field.

Counterplay:
distance, interruption, movement outside the region, prepared structures, gravity/law counter-effects if later authored.

Failure criterion:
The design fails if the seed gains infinite pull, permanent duration, or unrestricted scale.

## COUNTER_EPI_003 — Adaptive Arsenal

Primary weaknesses:
- learned templates only;
- finite biological reserve;
- whole-body viability must be maintained;
- transformation and reversion take resources/time.

Counterplay:
force rapid switching, exhaust available reserve, exploit unavailable template needs, pressure during transition.

Failure criterion:
The design fails if the ability becomes unrestricted shapeshifting, unlimited mass generation, or free arbitrary matter creation.

## COUNTER_EPI_004 — Spatial Dominion

Primary weaknesses:
- bounded field;
- extremely high sustained cost;
- path complexity increases burden;
- external topology remains unchanged.

Counterplay:
leave the field, create many simultaneous route demands, disrupt concentration, use spatial counter-effects, exploit field-collapse windows.

Failure criterion:
The design fails if Spatial Dominion becomes permanent global topology editing or unrestricted teleportation.

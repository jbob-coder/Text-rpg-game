## COUNTER_LEG_001 — Event Reversal

Natural limits:
- finite recent window;
- bounded radius;
- valid reference state required;
- exclusions/anchors create reconciliation complexity;
- repeated use creates severe system strain.

Counterplay:
- act outside the recorded zone;
- exceed the valid time window;
- create complex zone-boundary crossings;
- exploit explicit anchors;
- force repeated costly reversals;
- deny clean snapshot/reference conditions.

Failure condition:
The design fails if Event Reversal becomes unrestricted timeline editing, resurrection by default, infinite repeated rollback, or restoration of unspecified state.

## COUNTER_LEG_002 — World Gate

Natural limits:
- calibrated anchors required;
- major energy required;
- preparation required;
- finite aperture, duration, and throughput;
- anchor/reference integrity matters.

Counterplay:
- deny or invalidate anchors;
- interrupt calibration;
- deny external energy;
- exploit preparation/opening time;
- create reference drift;
- exceed safe throughput.

Failure condition:
The design fails if World Gate becomes instant unanchored teleportation, arbitrary dimension travel, limitless throughput, or free permanent portals.

# Acceptance gate

Legendary rarity changes strategic possibility, not the requirement for prerequisites and counterplay.

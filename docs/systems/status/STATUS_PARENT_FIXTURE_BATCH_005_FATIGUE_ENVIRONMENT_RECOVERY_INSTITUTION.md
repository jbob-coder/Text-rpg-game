# Part A — Command-structure familiarity

## 1. FIX_CMD_001 — Known organization/role/protocol

Preconditions:
- actual institution ID exists;
- character has a legitimate known role;
- current workflow/protocol is known.

Expectation:
- parent system may resolve procedural familiarity/error;
- passive does not create authority.

Current readiness after this batch:
`QUALITATIVE_FIXTURES_READY`.

## 2. FIX_CMD_002 — Temporary reassignment

Expectation:
- known general command habits may help;
- unfamiliar role-specific procedure can still impose error;
- parent role assignment remains authoritative.

## 3. FIX_CMD_003 — Stale protocol

Expectation:
- familiarity with old procedure does not guarantee current correctness;
- protocol version must be checked.

## 4. FIX_CMD_004 — Unauthorized role boundary

Expectation:
- no passive grants command authority, clearance, credential, or obedience;
- workflow familiarity cannot bypass authorization.

## 5. FIX_CMD_005 — Gate Twelve boundary

Confirmed Gate Twelve civic/maintenance/restricted contexts make formal workflows plausible.

They do not yet establish:
- institution ID;
- command hierarchy;
- credential/clearance system;
- formal protocol owner.

Therefore current Gate Twelve use remains context-only.

# Part B — Fatigue performance decay

## 6. FIX_FAT_001 — Ordinary sustained exertion

Expectation:
- parent system can represent performance decay from accumulated eligible fatigue;
- fatigue remains distinct from current Stamina amount.

Current readiness:
`QUALITATIVE_FIXTURES_READY`.

## 7. FIX_FAT_002 — Conditioned/paced favorable case

Required relationship:
`DECAY_favorable <= DECAY_adverse`
for matched work where conditioning/pacing legitimately matters.

No coefficient is assigned.

## 8. FIX_FAT_003 — Repeated demand

Expectation:
- accumulated fatigue can worsen with repeated sustained effort;
- passive cannot make repeated load free.

## 9. FIX_FAT_004 — Injury separation

Expectation:
- injury penalty/state remains separate;
- fatigue passive cannot erase injury.

## 10. FIX_FAT_005 — Stamina separation

Expectation:
- two characters with the same current Stamina may still differ in accumulated fatigue if parent design supports that state;
- Stamina restore does not automatically erase fatigue unless explicitly authored.

# Part C — Sleep restoration

## 11. FIX_SLEEP_001 — Adequate valid sleep

Expectation:

Current readiness:
`QUALITATIVE_FIXTURES_READY`.

## 12. FIX_SLEEP_002 — Interrupted but valid sleep

Expectation:
- restoration may be lower than matched uninterrupted case;
- interval can still be valid if parent rules allow.

## 13. FIX_SLEEP_003 — Inadequate sleep boundary

Expectation:

- deprivation consequences remain.

## 14. FIX_SLEEP_004 — Save/load across sleep

Expectation:
- elapsed sleep/recovery applies once;
- reload cannot replay restoration;
- world-time semantics remain authoritative.

Expectation:

Current readiness:
`QUALITATIVE_FIXTURES_READY`.

## 24. FIX_EMO_002 — Safe/supportive recovery context

Required relationship:
recovery can be no worse than a matched constrained/adverse context when support is legitimately relevant.

No rate is assigned.

## 25. FIX_EMO_003 — Repeated recent stress

Expectation:
- parent system may slow or complicate recovery;
- passive does not erase accumulated context.

## 26. FIX_EMO_004 — Active-threat boundary

Preconditions:
- threat/event is still active.

Expectation:
- post-event recovery resolver does not falsely treat the event as resolved;
- other crisis/stress systems remain active.

## 27. FIX_EMO_005 — Memory/relationship persistence

Expectation:
- recovery of functional performance does not delete memory;
- relationship/reputation changes remain;
- emotion is not rewritten out of history.

## 28. Resolve interaction

Resolve may influence or be influenced by mental-pressure systems, but:
- emotional recovery is not automatically Resolve regeneration;
- Resolve amount is not identical to emotional state;
- cross-resource/state conversion requires explicit parent rules.

## 29. Cross-system environment rule

Heat/cold performance, fatigue, sleep deprivation, injury, core resources, and emotional state must remain separately inspectable.

A character may simultaneously be:
- fatigued;
- low Stamina;
- heat-stressed;
- injured;
- emotionally strained.

One passive does not collapse these into a universal endurance modifier.

## Meaning of “baseline complete”

For every family, the documentation now identifies at minimum:
- the bounded effect identity for all ten records;
- the authoritative state categories the family will need;
- the primary scaling direction and hard caps;
- qualification/evidence expectations;
- major cross-family overlap risks;
- player-safe hidden-information requirements;
- knowledge/secrecy posture review;
- principal implementation/test blockers.

## What is not complete

This milestone does **not** mean:
- any passive is canon-promoted;
- compact unlock thresholds are final;
- numeric coefficients are final;
- cross-family stacking is fully normalized;
- all state owners are mapped to runtime modules;
- all institutions, professions, factions, schools, or historical cases are authored;
- all knowledge-row revisions are approved;
- implementation mapping is complete;
- runtime tests exist.

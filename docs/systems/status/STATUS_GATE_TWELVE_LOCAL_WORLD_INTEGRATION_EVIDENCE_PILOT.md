## 1. Evidence boundary

Confirmed local implementation/documentation facts include:
- Gate Twelve District exists as the proof region;
- Platform Nine is a municipal tram-depot evacuation platform;
- Relay Workbench is a maintenance/technical location;
- Service Gate Twelve is a controlled/restricted maintenance threshold;
- Service Tunnel is restricted lower infrastructure;
- Quiet Stair is an alternate maintenance/evacuation branch;
- Trace Chamber is a Trace reproduction/stabilization space;
- Depot Plaza is a public surface-facing meeting/orientation area;
- Municipal Archive is a records annex;
- Workshop Row contains repair shops / municipal contractors.

These facts support **local civic, maintenance, records, contractor, emergency, and restricted-access contexts**.

They do not establish:
- a sovereign government;
- a national military;
- a global regulator;
- the proposed Arden Municipal Authority as canon;
- the proposed Arden Crossing / Alder Basin names as canon;
- global technology policy;
- a universal ability-registration law.

## 4. Knowledge-profile implications

Gate Twelve local evidence can justify **context availability**, but cannot by itself prove global public/school/government knowledge.

Therefore:
- a local maintenance context can support `PROFESSIONAL_KNOWN` or `INSTITUTIONAL_KNOWN` later if an actual local role/training path is authored;
- restricted infrastructure does **not** justify `GOV_CLASSIFIED` by itself;
- a Municipal Archive does **not** justify classified Status knowledge;
- public Depot Plaza does not imply public knowledge of hidden passive unlock conditions.

This distinction should be used when adjudicating Knowledge Waves A/B/C.

## 5. Parent-world proposal separation

The following remain proposal-only and cannot be used as confirmed knowledge holders:
- Arden Municipal Authority;
- Arden Crossing;
- Alder Basin;
- proposed parent-facing route stubs.

If later approved, they may become concrete world entities for Status integration.

Until then, use local context IDs or role classes only.

## 6. Immediate world-integration result

The Status corpus now has a proof of how to integrate mechanics with world evidence **without inventing a government/faction/institution**.

Accepted method:
1. start from confirmed local place/function evidence;
2. identify plausible mechanic relevance;
3. label it as context candidate;
4. do not infer training, policy, or knowledge ownership;
5. wait for actual world entity/policy records before advancing to `WORLD_ENTITIES_LINKED` or `LAW_POLICY_LINKED`.

No mechanic is canon-promoted by this pilot.

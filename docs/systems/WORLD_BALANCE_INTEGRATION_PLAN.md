# THE GAME — World Balance & Progression Integration Plan

Status: **FOUNDATIONAL / NUMERIC MODEL NOT LOCKED**
Parents:
- `docs/systems/PROGRESSION_MASTER_PLAN.md`
- `docs/world/WORLD_SCALE_DOCUMENTATION_BLUEPRINT.md`
- `docs/systems/TACTICAL_COMBAT_MASTER_PLAN.md` once combat is approved

## 1. Purpose

Define how player progression, NPC/beast strength, world regions, items, economy, quests, and combat remain coherent without turning the world into universal level scaling.

## 2. Principle

The world should possess objective danger.

Player level/progression may influence encounter selection within limits, but regions, factions, beasts, and named entities should retain authored power identities.

## 3. Balance layers

- character power;
- equipment power;
- ability/skill power;
- party power;
- enemy/beast power;
- encounter difficulty;
- region danger;
- resource/economy value;
- quest reward;
- recovery/time cost.

## 4. Regional bands

Each region eventually defines:
- civilian baseline;
- common threat band;
- trained professional band;
- elite band;
- apex/unique threats;
- environmental hazards;
- reward band;
- equipment access;
- escape options.

Exact numbers pending.

## 5. World communication

Players should learn danger through:
- map markers if known;
- NPC warnings;
- visible beast signs;
- faction control;
- equipment requirements only if system uses them;
- prior knowledge;
- environmental art.

Do not require hidden numeric omniscience.

## 6. Progression curve

Need:
- early/mid/late progression;
- attribute/skill growth;
- ability mastery;
- equipment contribution;
- class/rank contribution if adopted;
- diminishing returns;
- caps;
- catch-up;
- specialization.

## 7. Anti-snowball

Persistent systems can compound advantages.

Need controls for:
- economy wealth;
- overpowered equipment;
- rival farming;
- XP farming;
- training loops;
- resource regeneration;
- ability mastery;
- loot respawn.

Controls should emerge from time, scarcity, diminishing returns, risk, and world response rather than arbitrary invisible nerfs.

## 8. Encounter balance

Later formula should consider:
- party state;
- injury/resources;
- terrain;
- objective;
- enemy composition;
- escape;
- reinforcements;
- information.

Difficulty is not just HP totals.

## 9. Loot balance

High value should correspond to:
- danger;
- rarity;
- access;
- scarcity;
- skill;
- world consequence.

## 10. Economy balance

Prices should reflect:
- local supply;
- transport;
- scarcity;
- law/faction;
- world events;
- quality.

## 11. Training balance

Training loops like Trace Chamber need:
- time;
- resources;
- recovery;
- prerequisites;
- mastery thresholds;
- diminishing value where appropriate.

## 12. NPC/rival balance

Recurring rivals should evolve plausibly, not rubber-band perfectly to player power.

Potential:
- faction resources;
- actual victories;
- training/equipment access;
- injuries;
- promotions;
- intelligence about player.

## 13. Beast balance

Species power should be ecological and regional.

Need:
- juveniles/adults/elite/unique only if biology supports;
- pack size;
- territory;
- resource reward;
- migration;
- escape behavior.

## 14. Difficulty modes

Not yet decided.

If used, prefer changing transparent parameters/AI assistance over rewriting world canon.

## 15. Validation

Need simulation/tests for:
- progression curves;
- encounter outcomes;
- training loops;
- economy inflation;
- loot rates;
- rival growth;
- regional danger.

## 16. Open decisions

- numeric level model;
- whether level is visible;
- stat caps;
- XP;
- encounter budget formula;
- item power scaling;
- regional band values;
- difficulty modes;
- death/injury penalty.

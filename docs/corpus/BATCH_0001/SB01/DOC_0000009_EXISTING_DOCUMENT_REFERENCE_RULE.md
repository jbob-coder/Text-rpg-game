## Rule
Useful documentation that predates the numbered corpus is referenced as EXISTING::<repository-path> until an explicit migration assigns a numbered replacement.
Existing documents are not duplicated into the corpus merely to raise file count.

## Allowed relationships
A numbered document may reference, narrow, operationalize, explicitly supersede, or migrate ownership from an existing document.

## Duplication prohibition
Do not copy an existing document verbatim or near-verbatim into a numbered file unless a documented migration requires a new canonical unit and the old source is correspondingly classified.

## Migration rule
When replacing existing documentation: identify old path; classify KEEP/UPDATE/REWRITE/SUPERSEDE/MERGE/DELETE; issue new stable ID; link provenance; update indexes; preserve useful historical evidence.

# Conversation Context — Status UI, Ability & Passive Canon

Recorded: 2026-10-03 AST

Owner-established direction:

- humans receive the Status UI at age 18;
- schools gather for a public awakening/classification event;
- every human awakens exactly one primary ability;
- primary-ability rarity order is Common, Uncommon, Rare, Super Rare, Epic, Super Epic, Legendary, Prime Legendary, Unique;
- Unique means 1/1 in the universe for that ability identity;
- some abilities are objectively superior to others;
- a human cannot normally change the awakened ability;
- Level 100 creates an exception permitting ability change/replacement;
- only two humans in known history have reached Level 100 so far;
- Level is real in-universe and progresses from kills, including beast kills and PK;
- humans may acquire many passive abilities in addition to the one primary ability;
- passives can unlock through extreme experience/adaptation/training and other authored requirements;
- passives remain completely hidden until the character satisfies their requirements;
- once requirements are satisfied, the Status UI can reveal the passive;
- many passives are intended to exist;
- some passives/requirements are already known in-world but deliberately kept secret;
- a large part of the long-range documentation program should map and clarify abilities, passives, hidden requirements, discovery, rarity, evolution, knowledge and related content.

New authority:
- `docs/systems/STATUS_UI_ABILITIES_AND_PASSIVES_MASTER_PLAN.md`

Important correction to earlier progression framing:
- global Level is not merely an optional summary concept; it is now target-game canon as part of the Status UI;
- Level coexists with attributes, skills, mastery, classes, professions, ranks, knowledge and other progression layers.

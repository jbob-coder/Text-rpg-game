# GAME_CONTEXT_LOGS

Repository-native cross-chat continuity records.

## Authority

These logs do not override implementation state. Read order:

1. current repository files and exact branch/HEAD;
2. fresh build/test/runtime evidence;
3. `docs/THE_GAME_MASTER_TASK_REGISTER.md`;
4. implementation/handoff documents;
5. these conversation-context logs;
6. chat memory/historical summaries.

Use these files to preserve user decisions, corrections, constraints, rejected directions and unresolved work that may not yet exist as runtime code.

## Safety boundary

Routine reversible repository decisions may be made without repeated confirmation when they preserve data, keep history intact, avoid `main`, and remain within the current task. Irreversible, external, destructive, security-sensitive, billing, release, visibility, or shared-history operations still require an explicit approval boundary.

## Supply-chain stages

Typical legal chain:
SOURCE
-> FIELD RECOVERY / EXTRACTION
-> QUARANTINE OR PRIMARY INSPECTION
-> ASSAY
-> CERTIFIED STORAGE
-> PROCESSING / REFINEMENT
-> LICENSED TRANSPORT
-> INDUSTRIAL / MEDICAL / GOVERNMENT USER
-> WASTE / RECOVERY / RECYCLE

Not every crystal passes through every stage.

## Reference philosophy

The encyclopedia answers:
"Can this entity, threat, technology, law, faction, or condition logically exist in this scene?"

It is not written as prose history.

Every record should be queryable by as many of these keys as apply:
- ERA
- YEAR_RANGE
- WORLD
- REGION
- BIOME
- THREAT_LEVEL
- SPECIES
- FACTION
- TECHNOLOGY_LEVEL
- LEGAL_CONTEXT
- KNOWLEDGE_LAYER
- ACADEMY_RELEVANCE

## Cross-reference rule

A history chapter may summarize an entity.
The encyclopedia owns its technical definition.

Example:
- history book explains what a beast outbreak felt like;
- creature entry defines the species;
- ecosystem entry explains its niche;
- law entry explains response authority;
- event entry records the outbreak;
- scenario layer checks whether that combination fits a future scene.

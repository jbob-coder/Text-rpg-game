# Academy Continuity Anchor

Status: PROTECTED_NARRATIVE_PILLAR
Created: 2026-09-29

## User requirement

The Academy must remain a core aspect of the narrated game.

## Protected function

Until stronger campaign-specific canon defines it, the Academy serves as a major recurring institution capable of supporting:
- structured learning and training;
- social relationships and rivalries;
- instructors and authority;
- evaluation and progression;
- access to restricted knowledge;
- faction recruitment and surveillance;
- consequences for ability use;
- missions or field exposure;
- downtime and recovery;
- character development outside direct combat.

This is a functional anchor, not permission to import a named academy from another project.

## What the director may alter

The director may create or change, using stable IDs and traceable canon states:
- students;
- faculty;
- departments;
- rules;
- schedules;
- exams;
- missions;
- disciplinary systems;
- internal factions;
- secrets;
- architecture;
- traditions;
- scandals;
- security procedures;
- curriculum;
- political pressures;
- external threats;
- Academy responses to world events.

## What the director must not do silently

- remove the Academy from the story;
- replace it with an unrelated institution without explicit user direction;
- import an academy name, roster, geography, or chronology from another Jack continuity;
- assume Jack's enrollment state if it is not recovered;
- make every world event center on the Academy;
- use the Academy to override Jack's agency.

## Integration rule

The Academy should feel embedded in the wider world.

World events may influence its:
- funding;
- security;
- curriculum;
- recruitment;
- public reputation;
- species/faction policies;
- portal access;
- technology;
- field operations.

Likewise, Academy decisions may create consequences outside campus.

## Canonization

When the Academy's exact identity is established, create a campaign-specific institution file with a stable `INSTITUTION_*` ID and update LIVE_WORLD_STATE to reference it.
